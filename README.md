# Programs

A shelf for small, finished programs.

| Program | What it is |
| --- | --- |
| [Lantern](lantern/) | A table companion for 5e nights. Players build a character, then roll, draft notes, and talk or whisper. The DM watches the party, whispers back, and keeps the prompts and the encounter budget. |
| [Grocery List](grocery-list/) | An Android app that turns a pasted or shared recipe into an interactive grocery list, merging amounts across recipes and grouping items by store section. |
